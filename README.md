## Summary

This is a web tool to automatically crop maps into the correct size for planet coaster.

## How to use

* Go to your preferred maps site (I like google maps and google earth) **If using google earth, it is recommended to turn off 3D buildings**
* Upload the image to the website
* Enter the ride name
* Click set ruler
* Click on both ends of the map ruler
* Type in how long the map ruler is, and select the correct units from the dropdown
* Enter the width of the screen you will use in game (for example 64m if using 32m screens at 2x scale)
* Click download
* Unzip the images into the planet coaster user content folder
* You may need to rotate the screens in game depending on what direction you are facing.
